Programa en Java CRUD alumnos. Los datos se almacenan en alumnos.txt.

Instrucciones de ejecución
Dentro de neatbeans.
Colocar Main.java y MetodosCRUD.java en la misma carpeta.
Abrir una terminal en esa carpeta.
Compilar:
javac Main.java MetodosCRUD.java
Ejecutar:
java Main
Seguir las opciones que aparecen en el menú.
